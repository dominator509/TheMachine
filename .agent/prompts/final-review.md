# Prompt: Final Review

Read `AGENTS.md`, `COMMANDS.md`, `.agent/PLANS.md`, and the active ExecPlan.

Steps:

1. Run required full verification.
2. Run production-readiness check if applicable.
3. Run `git diff --name-only`.
4. Compare changed files with expected files.
5. Verify acceptance criteria and non-goals.
6. Verify docs/decisions are updated.
7. Verify no secrets or production data.
8. Update Outcomes & Retrospective.
9. Report ExecPlan completed, changed files, commands/results, acceptance status, decisions, assumptions, risks, and production-readiness status.
