# Incident Response Checklist

- [ ] Detect incident
- [ ] Capture run ID, version, environment, timestamp
- [ ] Triage severity
- [ ] Stop destructive or repeating actions
- [ ] Preserve redacted logs and diagnostics
- [ ] Mitigate impact
- [ ] Communicate status if user-impacting
- [ ] Resolve root cause
- [ ] Verify fix
- [ ] Add regression test
- [ ] Update runbook
- [ ] Document postmortem
- [ ] Follow up corrective actions
