# Rollback Checklist

- [ ] Rollback trigger identified
- [ ] Rollback owner identified
- [ ] Current and target versions recorded
- [ ] Logs/diagnostics preserved
- [ ] Application rollback selected
- [ ] Database considerations reviewed
- [ ] Config rollback considered
- [ ] Feature flag rollback considered if applicable
- [ ] Approval obtained when production/user data involved
- [ ] Smoke after rollback passes
- [ ] User impact communicated
- [ ] Postmortem created
