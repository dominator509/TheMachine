# Agent Readiness Checklist

- [ ] Exactly one active ExecPlan is identified
- [ ] ExecPlan is self-contained
- [ ] Files to read first are listed
- [ ] Files to change are listed
- [ ] Expected changed files are listed
- [ ] Forbidden changes are listed
- [ ] Exact commands are listed
- [ ] Expected command outputs are listed
- [ ] Acceptance criteria are observable
- [ ] Non-goals are explicit
- [ ] STOP conditions are referenced
- [ ] Recovery rules are included
- [ ] Bounded retry rule is included
- [ ] Diff review is required
- [ ] No hidden context is required
- [ ] No vague requirements remain
- [ ] Agent is instructed not to ask for next steps
